# Ежедневная вайфу — Telegram inline-бот

Бот выдаёт каждому пользователю один случайный арт на день.
Арт держится до смены суток, у каждого человека свой.

## Как пользоваться (обычному юзеру)
1. В любом чате написать `@имя_бота waifu`
2. Сверху выпадет превью — тапнуть по нему
3. В чат приедет арт с подписью «Дорогой <ник>, сегодняшняя вайфу: <имя>✨»
   Имя кликабельно и ведёт на пост в канале (если при добавлении была ссылка).

## Как пополнять базу (админу)
В личку боту прислать фотку. В подписи к фотке — имя персонажа
и ссылка на пост канала (две строки, либо скрытая ссылка через выделение).
Бот ответит «✅ Арт запомнен».

## Запуск
pip install -r requirements.txt
python bot.py
